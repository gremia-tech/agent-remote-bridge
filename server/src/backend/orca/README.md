# Orca adapter

`createOrcaBackend({connectionFile, epoch})` implements the same HostBackend as Herdr. The bridge runs beside a protocol3 Orca runtime; one explicit runtime-scoped local access file stays server-side. Separate bridge state/ports support Herdr and Orca concurrently. [Operator setup](../../../../deploy/orca/README.md).

The unmodified upstream v2 crypto/handshake subset under `server/vendor/orca` is MIT, pinned to1.4.237/071747853f5995ee233b36751613f09a60007c2b. TweetNaCl1.0.3 is frozen in bun.lock. Every channel pins the native public key, uses authenticated v2 framing/counters and rejects legacy/plaintext fallback. An explicit private-file localEndpoint wrapper can route a LAN-advertised native link to its actual loopback listener while retaining the original key/token.

Catalogs are bounded/complete. Worktree and terminal inventory refreshes are sequential because parallel refreshes invalidate Orca's native inventory generation; concurrent callers coalesce an in-flight catalog without a stale TTL cache. Pane identity hashes bridge/runtime ID, incarnation-bound handle, PTY/layout identity and native agent identity. Native handle lifecycle is the authority: expectedIncarnationId is also sent, but it is not assumed to be independently enforced by every unary method in1.4.237.

Observers subscribe without client/viewport claims; snapshots must contain serialized ANSI. Controllers subscribe as explicit desktop viewers, then claim geometry after the snapshot; an existing native phone-fit requires explicit takeover. Bridge leases are exclusive among companion devices; Orca desktop/native clients can still interact, so this is not a global desktop ownership claim. Closing an observer cannot delete a controller binding. Native stream closure/identity replacement closes its lease. Writes use native settlement; transport loss or unproven acknowledgment is unknown, never automatically replayed. No native RPC proxy or arbitrary method selection is exposed to the phone.

File/Git inspection is additionally restricted to positively local execution identities and the existing contained, bounded Git inspection functions; ambiguous/foreign roots are refused. Unsupported provider conversation binding returns a supported=false DTO with live output available. Native agent startup into an existing pane is unavailable. Importing a repository does not create a worktree; custom tab/split directories are refused. Input is UTF8; non-UTF8 raw bytes/server scrolling are unavailable. See deployment setup for the tested-version and remote-PTY limits.
