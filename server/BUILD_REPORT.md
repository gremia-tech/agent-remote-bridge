# Host bridge implementation handoff

Verified 23 October 2026 with Bun 1.3.9 on Linux. `bun run --cwd server typecheck` passed. `HERDR_REAL_TEST=1 bun test --cwd server` passed **76 tests, 247 assertions, zero failures** across six files. The opt-in integration used a fresh temporary Herdr config/socket/server/workspace only; its owned server and directory were removed. No production Herdr session was controlled.

The bridge core now implements HTTPS enrollment, hashed 256-bit invitations/credentials, transactional single-use pairing, read/control scopes, CLI administration and revocation, explicit expiring controller leases, independent pane identity invalidation, bounded authenticated terminal streaming, inspection/structural routes, and a durable mutation journal. Pending operations recover as unknown rather than executing again. Queue admission is rechecked before dispatch after waiting; revocation is rechecked after asynchronous identity lookup. Failures never return arbitrary backend exception messages.

The 17 core cases cover concurrent pairing, expiry/replay, persisted-secret absence, private permissions, origin/scope/query-token rejection, bounded bodies and responses, read-only observation, explicit takeover, cross-process active revocation, expiry/stale targets, concurrent operation replay/body conflict, device-scoped operation lookup, ambiguous delivery, restart recovery, structural target validation, real hostname-valid HTTPS pairing, queued unknown operations, input/acquisition revocation races, controller cache resubscription, independent identity invalidation, and CLI failed-start cleanup.

`src/cli.ts` is the entry point. `init`, `serve`, `pair`, `devices`, and `revoke` accept an independent `--state` directory; CLI setup accepts explicit advertised URL, SANs, interface, port, Herdr executable and primary session. Pairing JSON/URI matches protocol/v1. Optional notifications are authenticated through the root-owned module and close before database shutdown. Exact usage and resource limits are documented in README.md.

`THIRD_PARTY_NOTICES.md` includes the extracted relay MIT notice, all 29 installed production dependency licenses, and the upstream Bun 1.3.14 runtime notice. Reproduce npm notices with `bun server/scripts/notices.ts`; recheck runtime notices if release compiler changes. Original server source is Apache-2.0. Compiled binaries must ship their notices and matching source/frozen lockfile.

Local Bun 1.3.9's self-contained compiler produced invalid zero-prefixed output despite reporting success; those temporary artifacts were removed and are not release artifacts. The parent is independently building/verifying Bun 1.3.14 macOS/Linux artifacts. Source/TLS tests do not establish binary portability, physical iPhone behavior, public relay deployment, APNs delivery or an independent security audit. This handoff makes no exactly-once terminal side-effect claim. All work remains uncommitted for parent integration.
